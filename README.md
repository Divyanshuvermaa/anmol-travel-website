# Anmol Travels – Char Dham Yatra Booking Website

A responsive travel booking website built for **Anmol Travels**, a Char Dham Yatra tour business based in Haridwar, Uttarakhand. The site covers packages and taxi services across Haridwar, Rishikesh, Auli, and Chopta.

🔗 **Live Site:** https://anmol-travel.netlify.app

## Features

- **Packages** – Char Dham Yatra tour packages
- **Taxi Service** – Booking for local and outstation taxis
- **Enquiry Form** – Direct customer enquiries
- **Cost Calculator** – Trip cost estimation
- **Itinerary** – Day-wise travel plans
- **Packing List** – Trip preparation checklist
- **Budget Planner** – Travel budget breakdown
- **Admin Panel** – Lets the business owner update site content without touching code

## Tech Stack

- HTML5, CSS3, JavaScript
- Single-page responsive design
- Hosted on Netlify
- Built using agentic AI-assisted development (Bob) to accelerate coding and iteration

## About

This project was designed and developed end-to-end — from UI/UX to deployment — to give a small tourism business a professional, easy-to-manage online presence for handling real customer enquiries.
